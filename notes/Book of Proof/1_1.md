## 1. Definitions, in my own words

A Set of collection of elements.
Elements can be anything but usually numbers in mathermatics
Sets can infinate or finite
Notation { 1,2,3} or {...,-1,0,1,...} for infinate
sets are equal if they have same elemets, independent of order
Sets notated by Capital letters
`x ∈ A`  "x is in A" / "x is an element of A" 
`x ∉ A`  "x is not in A" 
N is set of positive whole numbers
Z is set of integers (Pos, neg, zero whole numbers)
R is set of real numbers
Q is set of rational numbers {x: x = m/n where m,n ∈ Z and n ≠ 0}
size (cardinality) of set  is denoted by |A| 
empty set {} has a size of 0, and no elements
Set builder notation (shorthand) {2n: n∈Z} written as expression:rule
Intervals can be open (Does not include end point) and closed (includes end point) and can be infinite (-∞,3) or(-3, ∞)  
	All of these are infinite sets since there a infinate number of points in a interval

## 3. Worked exercises+

Six problems, chosen so each one has a specific way to fail. Numbering is from Hammack 3rd edition (the free PDF); if yours differs, match by content.

1. {5a + 2b : a, b ∈ ℤ} — Part A, #15

2. {6a + 2b : a, b ∈ ℤ} — Part A, #16

Do these as a pair and do not just write the answer. For each, write why — an argument that every element you claim is in the set really is, and that nothing else is. These two sets are different, and the reason they differ is the single most important fact in Phase 2. This is the gcd question from Day 12 wearing a set-notation costume.

3. {x ∈ ℝ : x³ + 5x² = −6x} — Part A, #8

Factoring problem. There is a specific way to lose an element here, and most people lose it. If you get three elements, check you didn't get them by accident.

4. {x ∈ ℤ : |6x| < 5} — Part A, #13

Trivial-looking. Say precisely what the answer is and how it differs from ∅.

5. |{{1}, {2, {3, 4}}, ∅}| — Part C, #29

Then, unassigned by Hammack but assigned by me: also compute |{{{1}, {2, {3, 4}}, ∅}}| and |{∅, {∅}}|. Three cardinalities, one sentence each on why.

6. {3, 6, 11, 18, 27, 38, ...} — Part B, #22

The reverse direction: given elements, produce set-builder notation. State which index set you're using (ℕ or ℤ), because the answer depends on it and getting this wrong is invisible until it bites you.

Written question (not from the book). One paragraph, no more:

{1, 1, 2} and {1, 2} are the same set. Name a mathematical object for which they would not be the same, and name the Rust type that corresponds to each. Then: is there an operation that's cheap on one and expensive on the other?

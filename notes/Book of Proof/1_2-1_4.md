**Reading:** Hammack §1.2 (The Cartesian Product), §1.3 (Subsets), §1.4 (Power Sets).

Three sections in one unit because they are one idea: *building new sets from old*,
and keeping track of how big the result is.  §1.2 multiplies, §1.4 exponentiates,
§1.3 is the relation both of them are defined in terms of.  The cardinality
arithmetic — `|A × B| = |A|·|B|` and `|P(A)| = 2^|A|` — is the thread; if the
counting comes out right, the definitions are right.

## 2. Why the definition is that way

<!-- Two specific questions this time, both worth answering in writing: -->

**(a) Why is an ordered pair *ordered*, when a set is not?**  `{a,b} = {b,a}` but
`(a,b) ≠ (b,a)`.  So an ordered pair cannot simply *be* a set of its two entries.
Yet set theory has nothing but sets to build from.  Kuratowski's answer is

```
(a, b)  :=  { {a}, {a, b} }
```

Check that this actually works: show it recovers `a` and `b`, and show
`(a,b) = (c,d)` forces `a = c` and `b = d`.  Then say what goes wrong with the
obvious cheaper attempt `(a,b) := {a, {b}}`.  This is the same empty-box
reasoning as §1.1 — asymmetry manufactured out of nesting depth.

**(b) Why is `∅ ⊆ A` for every `A`, including `A = ∅`?**  Most people find this
false on first contact.  Answer it by writing out the definition of `⊆` as an
implication and seeing what the implication says when the hypothesis never fires.
The name for what is going on is **vacuous truth**; it is exercise 4 below.

## 3. Worked exercises

Six problems, each with a specific way to fail.  Numbering is Hammack 3rd edition;
if yours differs, match by content.

**1. Sketch `ℝ × ℕ` and `ℕ × ℝ` in the plane.** — §1.2

Describe each in one sentence, then answer: are they the same set?  Is `×`
commutative?  The failure mode is answering "they're the same up to relabelling
the axes" — that is a *bijection*, not an *equality*, and conflating the two is
the error that §1.1 #5 was also testing.  Name which one you have.

**2. `|A × B| = |A|·|B|` for finite `A`, `B`.** — §1.2

Prove it.  Then compute `|A × ∅|` and state what `A × ∅` actually is.  The trap:
convince yourself the formula still holds when one factor is empty, rather than
treating that as a special case to be excused.

**3. Let `A = {1, {1}, {1,2}}`.** — §1.3

True or false, one sentence of justification each:

```
1 ∈ A        {1} ∈ A      {1} ⊆ A      {{1}} ⊆ A
{1,2} ∈ A    {1,2} ⊆ A    ∅ ∈ A        ∅ ⊆ A
```

They are not all the same answer, and two adjacent-looking ones differ.  This is
the `∈` / `⊆` confusion, which is the single most common error in Chapter 1.

**4. Prove: `∅ ⊆ A` for every set `A`.** — §1.3

Two or three lines.  The proof is *vacuous* and that is the entire point — write
the implication out and say precisely why it holds, rather than asserting "there
is nothing to check."  This is your first vacuous truth; there will be many.

**5. Write out `P(∅)`, `P(P(∅))`, and `P(P(P(∅)))`.** — §1.4

Elements listed explicitly, plus cardinality of each.  The failure mode is
writing `P(∅) = ∅`.  It isn't, and your §1.1 Lean theorem is exactly the reason.

**6. Prove `|P(A)| = 2^|A|` for finite `A`.** — §1.4

**Two proofs**, because they teach different things:

- by induction on `|A|` — the counting argument;
- by exhibiting a bijection `P(A) → (A → {0,1})` — the structural argument.

You have already met the second one.  The function `m : S → {0,1}` from the
multiset discussion in §1.1 was a *characteristic function*, and this is where it
turns out to be the whole story.

### Lean target for §1.2–1.4

```
theorem powerset_mono (A B : Set α) : A ⊆ B ↔ 𝒫 A ⊆ 𝒫 B
```

Both directions.  `→` is routine.  `←` needs one idea: you are handed a fact about
*all* subsets of `A` and you get to choose which one to apply it to.  Pick well and
it is one line.  (Mathlib has this as `Set.powerset_mono`; prove it under your own
name first, then diff against theirs.)
